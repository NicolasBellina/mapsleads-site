# MapsLeads

**Site en ligne** · <https://nicolasbellina.github.io/mapsleads-site/>

Site de présentation en français de l’extension Chrome MapsLeads. Le site est statique et ne nécessite aucune dépendance.

## Développement
Depuis la racine du dépôt, lancer `python3 -m http.server 8000 --directory dist` puis ouvrir http://localhost:8000.

## Publication
Le dossier `dist/` contient la page, ses styles, ses interactions et ses visuels. Publier son contenu à la racine de l’hébergement statique.

[Voir MapsLeads sur le Chrome Web Store](https://chromewebstore.google.com/detail/mapsleads/aboocaficakknaeaiohodccancocjocf?hl=fr)
